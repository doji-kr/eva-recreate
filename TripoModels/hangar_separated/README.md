# 원본 격납고 에셋 분리 조사

대상: `TripoModels/mecha_3d_model/mecha_3d_model.fbx`.

Blender로 확인한 원본은 메시 오브젝트 1개, 폴리곤 5,134개, UV 레이어 1개입니다. UV 경계에서 중복된 정점은 좌표를 소수점 5자리로 비교하여 같은 연결 구조로 취급했습니다. 이 기준으로 분리된 연결 성분은 106개입니다. 모든 원본 폴리곤을 정확히 한 조각에 할당했으며, 분리 과정에서 새 표면을 만들거나 UV를 다시 펴지 않았습니다.

- `hangar_loose_parts.glb`: 원래 배치와 크기를 유지한 106개 메시 노드. 원본 텍스처 포함.
- `source/hangar_loose_parts.blend`: Blender 편집용 파일.
- `parts_inspection.tscn`: 면 수가 많은 30개 조각을 각기 비슷한 크기로 확대하여 나열한 확인용 씬. 이 씬의 상대 크기는 조립용 스케일이 아닙니다.
- `tools/asset_analysis/parts_preview.png`: 확인용 렌더 (실제 위치는 프로젝트 루트 tools/asset_analysis).

눈으로 확인한 재사용 후보: Part_008/009 드럼통, Part_011 플랫폼, Part_016 경고등, Part_018 상자, Part_000 굽은 배관. 명칭은 외형을 보고 붙인 후보 설명이며 원본에 부품 이름이 있는 것은 아닙니다. 조각을 106개 분리할 수 있다는 사실이 완성된 모듈 106개를 확보했다는 뜻은 아닙니다. 33개는 15면 미만의 작은 조각이고, 일부 큰 조각에도 예시 격납고나 로봇의 일부가 섞여 있습니다. 실제 조립 전에 방향·피벗·크기·뒷면 상태를 점검해야 합니다.

분리 조사 후, 사용자 요청에 따라 주요 부품을 메인 격납고 씬에 재사용했습니다. 분리 및 조사 스크립트는 `tools/asset_analysis/`에 있습니다.
